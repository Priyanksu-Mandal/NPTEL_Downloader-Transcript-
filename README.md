# NPTEL_Downloader-Transcript- 🎓

One solution NPTEL transcribe downloader.

A lightweight, standalone Windows executable (`.exe`) that downloads all video transcripts for any NPTEL course in one go. No need to install Python, configure environments, or run scripts—just enter the Course ID and get your study materials instantly.

## 🚀 Getting Started

### Installation

1. Go to the repository page at `[https://github.com/Priyanksu-Mandal/NPTEL_Downloader-Transcript-](https://github.com/Priyanksu-Mandal/NPTEL_Downloader-Transcript-)`.


2. Download the `NPTEL_Downloader.exe` file directly from the repository files.


3. Move the executable to a dedicated folder (e.g., `D:\NPTEL_Transcripts\`) where you want the downloaded transcripts to be saved.

## 💻 Usage

1. Double-click `NPTEL_Downloader.exe`.


2. A command window will open, prompting you for the **Course ID**.
> **Note:** You can find the Course ID in the NPTEL course URL. For example, if the URL is `https://onlinecourses.nptel.ac.in/noc23_cs14/`, the Course ID is **`noc23_cs14`**.


3. Type the Course ID and press **Enter**.
4. The tool will automatically fetch and download all available transcripts for that course into your current folder.
